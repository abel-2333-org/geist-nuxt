## 修复结论

### api-docs-field-item — modified / verified

1. 为 field name、type、format 增加 `translate="no"`，避免浏览器翻译技术标识。
2. 桌面 gutter action 改为 `lg:pointer-fine:flex`，trailing action 改为 `lg:pointer-fine:hidden`；宽屏粗指针设备不再失去可见 copy-link action。
3. 三个原生按钮补齐 `touch-manipulation`。
4. 到达提示改为独立 overlay：静态 `ring` / wash 由 CSS 承载，Web Animations 仅改变 `opacity`，不再动画 `boxShadow` / `backgroundColor`，也不会覆盖行级持久 focus outline。

保留既有有意重复：4 处 fact-row 与 lifecycle detail 双位置仍由 parity tests 锁定；没有足够收益支持新增 registry 拓扑。

### api-docs-enum-table — modified / verified

1. 移除 `UTabs :content="false"` 的外置面板结构，改用 Nuxt UI / Reka 的 content slot，让每个 tab 获得真实关联的 `tabpanel`。
2. 将共享面板抽到 `kits/api-docs/internal/EnumTablePanel.vue`，仍归属 `api-docs-enum-table` 同一 registry item；过滤、默认值、真实 overflow 探测与键盘滚动语义保持不变。
3. 新增合法 variant id 不告警测试，以及每个 tab 与 panel 双向 ARIA 关联测试。
