## foundation-semantic-badge — 解决 f-e927544cd93a(change: modified, status: verified)

**Finding 回顾(low)**:`references/components/data-display.md` 一边把 `icon` 标为可选、一边要求「务必配 icon + 文本」,而 WebhookBadge 合法地只传非空文本不传 icon;`label: string` 也可为空串。universal claim 与 API 自相矛盾。

**修法:收窄公开 claim**(而非在 API 层强制 icon):

- `data-display.md`:改为「`label` 必须是非空文本(调用方契约,含义由文本承载),`icon` 可选、用于额外强化」,并列出仓库内 preset 包装层的非空保证作为证据;

**依据**:HttpMethodBadge 对空输入显式回落 `UNKNOWN`(http-method-badge.spec.ts 覆盖)、LifecycleBadge / LifecycleNotice blank 覆盖回落 preset 文案(chrome-labels.spec.ts 覆盖)、WebhookBadge 是常量 `EVENT`——三个包装层已各自保证非空文本,「文本承载含义、icon 可选」与全部既有调用点一致,WebhookBadge 反例随收窄消失。**为什么不强制 icon**:词形本身是主信号的场景(EVENT、HTTP 动词)强配 icon 反而制造噪音,与既有校准冲突。finding 标记 `resolved`。

## api-docs-code-block — 修 2 处(change: modified, status: verified)

核证通过的部分:`trustHighlightedHtml` 信任门默认关、复制永远用 raw `code`(code-sample.md 两条 universal claim 核证成立);labels 完整句注入契约与 chrome-labels.spec.ts 的 useCopy 测试一致;`useCodeWrap` 共享+cookie 持久化 SSR 安全;`lang-preset.ts` 与 ResponseExample 共用、覆盖优先级正确;工具栏单行/truncate/min-w-0 符合响应式条款;`overscroll-behavior: contain` 已有。

**修复 1(medium):语言选择器空态陷阱**。原 `v-if="hasContent && languageItems.length > 1"` 在「当前语言无 code」时把语言选择器一起藏掉——空态提示写着 "Try another selection." 却移除了执行该提示的控件,读者被困;且与组件自述「选择控件在空态保持可见,只有内容相关控件隐藏」的原则矛盾(该原则已对 `#controls` 生效)。复现:`variants=[{language:'curl',code:'x'},{language:'node',code:''}]` 切到 node。改为 `v-if="languageItems.length > 1"`,wrap/copy 仍随内容隐藏。非破坏:API 不变,行为向文档化原则对齐。

**修复 2(medium):代码滚动区键盘不可达**。body 是 `overflow:auto` + `maxHeight` 的内滚区,原实现不可聚焦——纯键盘用户无法滚动阅读超过 24rem 的代码(wrap 开关只解决横向)。改为 `tabindex="0"` + `role="region"` + 可访问名(`title` 优先,缺省新增 `labels.codeRegion`,默认 `Code sample`)+ 仓库统一的 `focus-visible:outline-2 -outline-offset-2 outline-primary` 描边(负偏移因 section `overflow-hidden`,同 SchemaComposition 先例)。顺带 `<pre translate="no">`(web-design-guidelines:代码是标识符不是散文,机器翻译不得改写)。

**配套**:`ApiCodeLabels` 增加 `codeRegion`(加法、非破坏,RequestExample/ResponseExample 的 labels 透传自动生效);`code-sample.md` 同步两条关键点与 labels 清单;新增 `tests/component/code-block.spec.ts`(4 例:空态选择器可见性 ×2、region 可访问名 ×2)。

**为什么没改其它**:未做条件 tabindex(仅溢出时可聚焦)——需要测量与 ResizeObserver,复杂度不成比例,恒定 tab stop 是 axe 推荐的标准修法;未给 `langLabel` 的 overrides 做大小写归一——文档已约定小写键,归一是无谓防御。
