## api-docs-webhook-protocol — 解决 f-b1838c3b046a(change: modified, status: verified)

**Finding 回顾(medium,a11y)**:steps 超过 `maxScheduleSteps` 且调用方未传 `expandLabel` 时,折叠按钮 `aria-label` 回退 `+N`,读屏只听到「+5,按钮,已折叠」,无法从名称判断该按钮会展开重试节奏;与组件注释「展开/收起按钮提供可覆盖的英文默认文案」及 reference「展开按钮带可访问名」两条 public claim 不一致。

**修法:补实现使 claim 成立**(而非收窄 claim):`aria-label` 默认改为英文句 `Show ${overflow} more steps`(`expandLabel` 注入仍优先),视觉文案保持 `+N` 不变——视觉序列的紧凑性与可访问名的语义性各走各的通道,符合 web-design-guidelines「icon-only/符号按钮需要 aria-label」与 SKILL.md「结构 chrome 提供默认文案并允许覆盖」。`collapseLabel` 侧原本就有 `'Collapse'` 默认,不动。reference 与 props JSDoc 同步写明默认值。

**配套**:新增 `tests/component/webhook-protocol.spec.ts`(3 例:默认可访问名 + 视觉 `+N` 分离、注入覆盖优先、展开后 `aria-expanded` / `Collapse` / sr-only 全序列出现)。此前该组件只有纯函数测试(`tests/webhook-protocol.test.mjs`),aria 行为零覆盖,这是 finding 得以存活一轮的直接原因。

**为什么没改其它**:`hasWebhookProtocolContent` 对「blank summary + steps」的边界(section 因 summary 空白整段省略,但若有其它正文则 schedule 行仍渲染空总结句)属于调用方违反「summary 是可访问真源」的数据契约,组件层防御会掩盖数据 bug,不改;facts 行、`<dl>` 语义、chips 逐个 `aria-hidden` 复核均与 reference 一致。

## api-docs-response-example — 解决 f-985ff00a90aa(change: modified, status: verified)

**Finding 回顾(medium)**:code body 未传 `mediaType` 且首个 variant 为 `{ language: 'json', label: '', code: '{}' }` 时,`codeBodyLabel` 用 `variant.label ?? langLabel` 接受空串,`bodyItems` 生成无名选项——宽屏 media `USelect` 与窄屏 `URadioGroup` 均出现空标签,未按 reference 回落。

**修法**:把组件内 `statusText` 已有的「空白视为未提供」规则推广到同类回落链——`codeBodyLabel` 改为 `label?.trim()` → `langLabel(...).trim()` → `codeBodyTitle` 逐级回落;`bodyItems` 的 `mediaType` 同样 `?.trim() ||`(空白 mediaType 与 `undefined` 同待遇)。根因是 `??` 只拦 nullish、空串穿透,而 `CodeVariant.label?: string` 类型上允许空串。reference 同步标注「空白同 statusText 规则视为未提供」。新增 spec 用例断言 blank label → `'JSON'`、blank mediaType + blank language → `'Code example'`。

**为什么没改其它**:675 行单文件虽大,但三级选择收敛、容器查询折叠、语义面板三块高度耦合于同一状态机,拆分只会把 props 接线摊开、不减少复杂度——上一轮已核证其收敛逻辑,不做拆分 churn;`compactControlLabel` / `compactControlAriaLabel`、live region、受控口复核均与 reference 一致。

## api-docs-request-example — 首轮扫描,修 1 处(change: modified, status: verified)

**为什么没改其它**:133 行无可精简;`variants` 空数组 → CodeBlock 空态、选择器仍可见的行为有文档且合理;不需要 ResponseExample 式的 `localScenario === undefined` 之外的收敛增强。
