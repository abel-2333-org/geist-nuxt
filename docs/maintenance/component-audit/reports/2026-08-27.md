## 逐组件依据

### foundation-copy-button（reference modified）

**核对项与依据**:

- **契约漂移修复**: `references/kits/api-docs/code-sample.md` 仍声称 `useCopy` 委托 VueUse `useClipboard({ legacy: true })`，与当前优先 Clipboard API、失败后使用 `document.execCommand('copy')` 明确结果的实现不符；本轮已同步该描述。
- **证据闭包**: 将 `code-sample.md` 纳入 CopyButton 的 `scope-v1` scope；今后该 cross-reference 的内容变化会使 CopyButton evidence stale，并触发对应 owner co-review。
- **精简/重构**: tooltip 与非 tooltip 双分支的模板重复（UButton + sr-only live region 各一份）是有意为之——组件多根 + `inheritAttrs: false`，`references/components/buttons.md` 明文规定布局类由外层元素拥有；`tests/component/copy-button.spec.ts` 钉住双分支 attrs 契约。
- **a11y/文案**: 动态 `aria-label`、polite live region、`focus-visible` 环与完整句 toast 约定均与 foundation references 及测试一致。
- **反向横扫**: 全仓复核 `navigator.clipboard`、`execCommand`、`useCopy` 与复制图标；剪贴板逻辑唯一归宿仍是 `useCopy`，`useFieldAnchor` 属复制深链接并滚动定位的明文豁免，无重复实现。

**为什么改**: 运行时实现正确，但权威 reference 仍描述旧实现；不能在 reference 与源码冲突时继续以 metadata-only clean 交付。
