### api-docs-response-example(ResponseExample)

- **晋升 / 精简 / 重构**:无。653 行单文件承担 scenario → status → body 三级收敛、媒体标签回落、状态 badge、窄容器 popover、三种语义面板与 live region,每段各有 `response-example.md` 契约条目;08-20 记录的 seam 重复 finding 已由 PR #103 抽成 `useExampleScenarioSelection` 落地(`f-a35a4e313b64` resolved 维持),status / body 两维刻意留在组件内(上下文收敛语义与 scenario 不同)。registry 两条依赖(`api-docs-code-block`、`api-docs-use-example-scenario-selection`)与 import / 模板实况一致,`lang-preset.ts` 经 code-block item 传递,无冗余闭包。
- **修复(本轮落地)——dev 重复 body id 检查只覆盖当前 status**。`response-example.md`「Body 语义」明文:scenario `id` / status 值 / body `id` 都是身份键,「重复键会静默解析到第一个匹配项,dev 模式下组件对此发出 `console.warn`」。实现里 scenario 与 status 两维遍历全树,但 body 维只遍历 `bodies.value`(当前 status)。**复现输入**:`<ResponseExample :scenarios="[{ id: 'a', label: 'A', statuses: [{ status: 200, bodies: [{ id: 'x', kind: 'empty' }] }, { status: 400, bodies: [{ id: 'x', kind: 'empty' }, { id: 'x', kind: 'empty' }] }] }]" />` 在 dev / test 下挂载,`console.warn` 调用 0 次(已在 main snapshot 上用临时 spec 实测);读者切到 400 后才告警,而 scenario / status 维度不需要任何交互。**修法**:把 body 循环并入 status 循环,消息带 scenario id(`within status 400 of scenario "a"`),`watchEffect` 只依赖 `scenarios`——顺带不再随每次选择变化重跑(原实现读 `bodies` / `currentStatus`,每次切换都触发一次全树遍历)。**行为契约**:dev-only 诊断,生产构建 tree-shake;既有消息前缀不变,08-20 的两条 warn 测试零改动跑绿;新增「warns about duplicate body ids under a status that is not selected yet」锁定。reference 对应句补「在挂载时对全部 scenario / status / body 一次性检查,不依赖当前选择」。severity low。**依据**:审计协议 §5 universal-claims 触发器(reference 的「dev 模式下发出 console.warn」有已知反例,只能修实现或收窄 claim,选修实现);`vue-best-practices` reactivity「watcher 依赖最小化」。
- **复核无回归的既有契约**(逐条对照 `response-example.md` State / A11y 节):scenario 受控 seam 挂载期一次性判定、未知 id 派生不回写;status 内部态记住最近显式选择、缺失时收敛首项;body 按 id 跨同上下文重排保留、上下文变化回首项、移除即丢弃(两个 pre-flush watch 注册顺序保证上下文重置后执行);`statusText` 空白回落 code、选项保留 `code + text`;media 标签 `mediaType` → variant label → `langLabel` → `codeBodyTitle`(`f-985ff00a90aa` resolved 维持);`@xl/response` 命名 container 切换 inline selects / compact trigger,popover 内 select + 两个 `URadioGroup`(`legend` 可见分组名),ResizeObserver 在触发器隐藏时关闭 portalled popover;persistent `role="status"` live region;文件面板下载为真实 `<a download>`;badge 文本 + 颜色双通道。`response-example.spec.ts` 22 用例(21 既有 + 1 新增)全绿。
- **Universal claims 核证**:源码注释「never parses OpenAPI」「empty — never "no example"」「unavailable — never fake code」「downloads are real links」「text + color, never color alone」,以及 reference「绝不显示为缺示例」「绝不伪造空 body」——由 `ResponseBody` 判别联合 + 各 kind 独立面板结构性保证;「dev 模式下发出 console.warn」修复后成立。
