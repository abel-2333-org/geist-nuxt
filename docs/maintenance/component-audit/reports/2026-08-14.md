上次审计 2026-07-28;其后经历 #51 EnumTable labels 透传与 #52 中立命名重构,当前行为面稳定。本次全量复审四维度:

- **精简**:模板内 4 处 fact-row `<dl>` 与 lifecycle detail 双位置(gate vs band 尾)是**有意重复**——源码有 keep-in-sync 注释,`field-item-structure.spec.ts` 有 wrap/对齐 parity 测试锁住;抽局部子组件会给单文件 slice 增加 registry 文件,收益为负。`childPaths` 每行 O(subtree) 重算在真实文档规模(数百字段)下可接受,未见性能证据不预优化(vue-best-practices §4:性能是后置 pass)。
- **优化**:a11y 核过——行焦点 `outline-hidden` + `focus-visible:outline-primary`(tested);锚点按钮 aria-label 含字段名且随 copied 态切换;图标 `aria-hidden`;高亮 cue 用 boxShadow 而非 outline(不吞键盘焦点环,WCAG 2.4.7,tested);`prefers-reduced-motion` 受尊重;色彩全语义 token,琥珀阶梯(CONDITIONAL 标签→条件行边框→caveat 填充→Beta 徽章)与 references 色彩分配一致;响应式走 `@container/field` 容器查询。
- **重构**:`<script setup>` + TS 质量良好;props 契约由 `FieldItemProps` 显式承载;`fieldRequiredState` 冲突语义(`required: true` 胜出、condition 照常渲染)有文档与测试。
- **Universal claims 核证**:`copyLink` 「只写剪贴板,从不导航」(`field-anchor.spec.ts` never-navigates 用例)、「stale positioning 不可能在用户离开后滚动」(navigation token + superseded / old-route-scope 用例)、「空 path 直接被拒」(invalid selector 用例)——均有测试反例防护,claim 与实现一致。

**为什么没改看起来可改的**:lifecycle detail 双位置去重、fact-row 抽局部组件、`childPaths` memo 化——三者都有明确的反面成本(registry 拓扑膨胀 / 无性能证据),且现状有测试与注释钉住意图,改动属 churn。
