## 原因与修复

Vue 3.5.39 的 SSR 将 `hidden="until-found"` 当作布尔属性，输出裸 `hidden`。浏览器得到普通隐藏内容，首次水合也没有将枚举值修复；用户打开再关闭后，客户端重新设置属性，才恢复原生查找能力。

采用 [Vue 上游修复 #13125](https://github.com/vuejs/core/pull/13125)，升级运行时和直接 compiler 依赖至 3.5.43，并使 lockfile 的实际 runtime、compiler、server-renderer 保持一致。Nuxt 4.4.8 的依赖范围允许该版本；没有添加 override 或 mounted DOM 修补层。

registry 的 Vue 要求同步为 `^3.5.43`。消费项目仍需自己安装满足要求的依赖；copy-in 不会替它修改 package.json。新增 registry 测试验证两个相关闭包拒绝 3.5.39/3.5.40、接受 3.5.43。
