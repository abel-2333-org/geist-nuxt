## Recorder — 共享 evidence owner 同批复审

原 recorder 只接受 planner 选中的两个 item；当功能修复命中其他已审计 item 的共享 scope 时，只能撤回修复或手工改 ledger，容易遗漏 owner、制造 stale evidence。

本次扩展 `recordResults`：

- 自动比较 base evidence scope 与功能 HEAD，并检测 registry `itemDigest` topology 变化；
- 要求 results 精确覆盖计划集合与全部受影响 co-review owner，缺失或无关 owner 均 fail closed；
- co-review 必须显式提供 `modified`、非空 notes、完整 scope 与 findings，且不得移除 HEAD 上仍存在、已被 diff 命中的旧 scope 路径；删除或 rename-old 的旧路径可移除；
- 计划项与 co-review owner 共用一个 evidence HEAD、当前 round 与完整 `lastPicked`，写入前全部验证并原子发布。

新增 regression 覆盖 changed scope、topology-only、无关/缺失 owner、跨 HEAD、删除旧路径、round 2→3 rollover 与 stale readback；`pnpm test:audit` 现为 22/22。
