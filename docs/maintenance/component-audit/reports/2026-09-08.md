### api-docs-code-block(CodeBlock + lang-preset)

- **晋升 / 精简 / 重构**:无。332 行单文件承担工具栏装配 + 语言选择 + 换行 + 委托复制 + 三态 body(code / `#body` / 空态)+ 双主题 token 切换,每段各有 `code-sample.md` 契约条目,08-06 / 08-27 已两次裁定不拆;registry 三条依赖(foundation、copy-button、use-code-wrap)与 import / 模板一致,`lang-preset.ts` 随本 item 分发并被 ResponseExample 共用,无冗余闭包。
- **修复(本轮落地)——`languageLabels` 覆盖键大小写敏感**。`langLabel` JSDoc 写「overrides → preset → capitalized id」,`code-sample.md` / `response-example.md` 写「覆盖优先」,但实现先把 id 小写再用小写键查覆盖表,覆盖表自身的键却不做归一。**复现输入**:`<CodeBlock :variants="[{ language: 'python', code }, { language: 'go', code }]" :language-labels="{ Python: 'Python 3' }" />` → 语言选择器显示 `Python`(preset)而非 `Python 3`,覆盖被静默丢弃;老实现下 `tests/component/code-block.spec.ts` 新增用例 `resolves python with { Python: 'Python 3' } to Python 3` 失败(已实测)。**修法**:精确小写键仍优先命中(保留旧优先级),未命中时按键大小写不敏感回退(`Object.entries(overrides).find(...)`,表规模 ≤ 十余项,每个 variant 一次),JSDoc 写明「id 与覆盖键均大小写不敏感;仅大小写不同的多键以精确小写键为准」;新增 5 条 `langLabel` 单元用例(含多键优先级)+ 1 条挂载 CodeBlock 断言 `USelect` items 的用例。**行为契约**:所有原本命中的输入命中结果不变,只有原本被丢弃的非小写键开始生效,非破坏性;ResponseExample 的 media 标签共用同一函数,两处同步受益、不产生分歧。severity low。**依据**:审计协议 §5「props/emits/slots 契约清晰」与「reference 与源码冲突时不得以 clean 交付」;`code-sample.md` `languageLabels` 行。
- **新 finding(low,open,deferred)——换行 toggle 的 ARIA 语义混用**。工具栏换行按钮同时设 `:aria-pressed="wrap"` 与随状态翻转的 `:aria-label="wrap ? t.wrapOff : t.wrapOn"`(`Turn on line wrap` ↔ `Turn off line wrap`)。**复现输入**:任意含 code 的 CodeBlock,读屏聚焦该按钮——关闭态播报「Turn on line wrap, toggle button, not pressed」,点击后播报「Turn off line wrap, toggle button, pressed」,动作式文案与 pressed 状态互相矛盾。**依据**:WAI-ARIA APG Button pattern 明文「It is critical the label on a toggle does not change when its state changes」,并指出若设计需要文案翻转则不应再用 `aria-pressed`;`focus-a11y.md`「纯图标按钮必须有可访问名称」只约束存在性,未约束一致性,本 finding 是其补充。**为什么不本轮修**:修法 ①(推荐)保留 `aria-pressed`、label 固定为状态无关名词(如 `Line wrap`),需在 `ApiCodeLabels` 新增键并决定既有 `wrapOn` / `wrapOff` 公开 i18n 键的去向——消费项目已本地化的键会失效,是公开契约变化;修法 ② 去掉 `aria-pressed` 保留动态 label(与 CopyButton 同惯例)则失去 toggle 语义。两者都改变辅助技术可感知的行为契约,按 §7 记 deferred 交人工决策。
- **复核无回归的既有契约**:语言选择器 >1 语言时恒可见(含当前语言无 code 的空态)、内容相关控件(换行 / 复制)随 code 隐藏;代码区 `tabindex=0` + `role=group` + `focus-visible` 内描边(`-outline-offset-2`——外层 `overflow-hidden` 会裁掉外描边,内描边是正确取舍)+ `translate=no`;`v-html` 在 `trustHighlightedHtml` 门后、复制永远取 raw `code`;`.dark` 下 `--shiki-dark` 能力检测切换随组件 scoped CSS 分发;`useCodeWrap` cookie 种子 `useState`、SSR 首帧正确;`labels` 合并保留 `copied` → `copySuccess` 兼容路径。`code-block.spec.ts` 14 用例(8 既有 + 6 新增)全绿。
- **Universal claims 核证**:新 JSDoc「Callers never have to normalise their keys」由大小写不敏感查找结构性保证并有测试;源码注释「Header / toolbar — ALWAYS a single row」由 `flex-nowrap` + 左右 `min-w-0` + 图标 `shrink-0` 保证,08-06 已核;`code-sample.md`「raw code 永远是真源」由 `CopyButton :value="current?.code"` 与 spec 断言锁定。

- **为什么没改看起来可改的**:
