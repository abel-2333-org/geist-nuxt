## api-docs-code-rail —— modified / verified

### 修复 1:ResizeObserver 目标失联(`43c6b39` → `70a3cd0`)

- **复现**:lg+ 溢出态下,代码卡从 empty 面板(如 204 no-body scenario)切到有 body 的 scenario。`CodeBlock` 的 `pre.raw-pre` 在 `v-if="hasContent"` 内,交换会**重建** `<pre>`;原实现只在 `onMounted` 绑定一次 RO 目标,新 `<pre>` 无人观察。溢出态下 wrapper 高度被 `:style` 钉住,此后 `<pre>` 单独长高不触发任何已观察目标的 resize → `natTop/natBottom` 永久陈旧,budgets 与把手 aria 值失真。
- **首版不足**:`43c6b39` 只在 `measure()` 内对比并重绑 `pre.raw-pre`,但 overflow 态的 pane wrapper 已被固定高度;empty↔content 可以在所有既有 RO target 尺寸不变时完成,因此不存在必然触发 `measure()` 的信号。旧测试手工调用 `ResizeObserver.trigger()` 掩盖了该生产缺口。
- **最终修法**:`70a3cd0` 在两个稳定 pane wrapper 上增加局部 `MutationObserver({ childList: true, subtree: true })`,只负责检测代码面 DOM 身份变化;变化时用 `unobserve(oldPre)` / `observe(newPre)` 增量维护 RO target 并调度现有单一 rAF。MutationObserver 不观察 attributes/characterData、不直接写响应式状态,几何变化仍归 ResizeObserver。

### 修复 1.1:语义 body panel 的自然高度

empty/unavailable/file 等语义面板没有 `.code-surface` / `pre.raw-pre`;原 fallback 返回 wrapper `offsetHeight`,但 overflow 态该值是旧预算而非自然高度。现有 `section` 时改取 `section.offsetHeight`,保留无 section 时才回退 wrapper,避免重测及时却仍按陈旧预算分配。
